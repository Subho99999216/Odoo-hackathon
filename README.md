# Dayflow - Human Resource Management System

Hackathon MVP based on the provided Dayflow HRMS requirements.

## Features

- Employee / HR authentication
- Role-based dashboards
- Employee profile management
- Daily check-in / check-out
- Attendance records
- Paid / Sick / Unpaid leave requests
- HR leave approval / rejection
- Payroll visibility
- HR employee and salary management

## Run locally

Requirements:
- Node.js 18+

Commands:

```bash
npm install
npm start
```

Open:

http://localhost:3000
