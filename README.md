# Dayflow HRMS - Hackathon

Folders are separated for the 3-person team:

- `frontend/` - employee-facing UI
- `backend/` - Express API and data
- `admin/` - HR/Admin panel

## Run backend
```bash
cd backend
npm install
npm start
```

## Run frontend
Open `frontend/index.html` with Live Server after the backend is running.
